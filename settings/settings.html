Custom Logic Rules

Add bonus points or penalties on top of the base scoring engine.

How do custom rules work?
How scoring works — Base scoring automatically evaluates proposals, budget, location, and posting time. Custom rules run on top as additive modifiers: positive points = bonus, negative points = penalty.
Rule anatomy — Each rule has 6 parts: Name (label), Field (what to check: proposals, budget, country, title, etc.), Operator (how to compare: contains, gte, lt, etc.), Value (what to compare against), Points (reward or penalty), Flag (optional badge label shown on the job card).
Examples:
• Bonus React jobs → Field: title, Contains, React, +20 pts, Flag: Has React
• Penalize high competition → Field: proposals, ≥ (gte), 50, -20 pts
• Prefer US clients → Field: country, Contains, United States, +15 pts, Flag: US Client
Tips — Points can be negative for penalties. All matching rules stack. Leave Flag empty if you only want to adjust the score without a visible pill badge. Title field lets you keyword-match job titles.
